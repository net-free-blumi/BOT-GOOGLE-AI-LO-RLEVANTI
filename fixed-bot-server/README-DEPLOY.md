# מדריך הפעלה, פתרון באג קישור מכשיר, ברקוד QR חי וסנכרון שרת (VPS)

## 📋 פירוט התיקונים המהותיים שבוצעו (גרסה 2.6):

### 1. 🛠️ פתרון באג "קישור המכשיר נכשל - משהו השתבש יש לנסות שוב":
- **שורש הבעיה:** ברגע שהמשתמש מזין את קוד הצימוד בן 8 הספרות בטלפון, שרתי וואטסאפ מנתקים את חיבור ה-WebSocket הראשוני עם קוד ניתוק `515` (`DisconnectReason.restartRequired`) כדי לבצע לחיצת יד מוצפנת (Handshake). בקוד הקודם לא היה מנגנון חיבור מחדש אוטומטי בסשני הנהגים בעת סגירה, מה שגרם לסוקט להיסגר כשהטלפון המתין, עד ל-Timeout והודעת שגיאה!
- **התיקון:** הוספנו חיבור מחדש מיידי ב-`session-manager.js` בעת סגירה (למעט 401 Logout אמיתי), כך שה-Handshake מושלם תוך שנייה והטלפון מתחבר בהצלחה מלאה.

### 2. 📷 תמיכה בסריקת קוד QR אמיתי באתר (וואטסאפ ווב):
- בלשונית **"קישור מכשיר"** באתר נוספה בחירה בין 2 אפשרויות:
  - 🔢 **קוד צימוד לטלפון (8 ספרות)** - אידיאלי למובייל בהעתקה בלחיצה אחת.
  - 📷 **סריקת קוד QR (וואטסאפ ווב)** - מציג ברקוד חי ברזולוציה גבוהה ישירות על המסך.
- הברקוד **מתעדכן ומתרענן אוטומטית כל 20 שניות** (כולל שעון עצר ורענון ידני) ומאפשר סריקה ישירה ממצלמת הוואטסאפ במכשיר!

### 3. 🔍 גילוי אוטומטי של מספרי טלפון בפניות פרטיות 1-על-1 (פתרון Meta LID):
- **מדוע בקבוצות זה עבד ובפניות פרטיות לא?** בקבוצות Baileys שומרת את `participantAlt` ו-`participantPN` ופונה ל-`signalRepository.lidMapping`. בפניות פרטיות הקוד בדק רק Regex בטקסט.
- **התיקון:** כעת, בכל הודעה פרטית נכנסת מול הבוט הראשי, הבוט סורק את `m.key.remoteJidAlt`, `m.key.participantPN`, `m.key.participantAlt` ומתשאל את ה-`signalRepository` של Baileys. ברגע שנמצא מספר סלולרי ישראלי אמיתי, הוא ממופה מידית, מוצג בירוק למנהל, וההתראה למנהל נשלחת עם המספר המדויק!

### 4. 🧹 איפוס מלא של כל הקוקיז ומיפויי LID (ניקוי שרת מוחלט):
- נוסף כפתור מיוחד באתר: **"איפוס מוחלט של כל הקוקיז"** בלשונית סשנים, בלשונית קישור ובלשונית הגדרות.
- פעולה זו מוחקת את כל התיקיות מתוך `auth/sessions/*`, ומנקה לחלוטין את `lid-map.json` כך שלא יישארו כינויים או מיפויים ישנים, **מבלי לגעת בבוט הראשי (`auth/bot`)**.

### 5. 🗑️ מחיקת כל בקשה (גם ללא טלפון/שם) במודאל פנימי:
- כל פעולות המחיקה והאישור מבוצעות דרך מודאל מעוצב (`ConfirmModal`) ללא שום הודעות דפדפן קופצות.
- ניתן למחוק כל בקשה לפי ה-ID שלה גם אם המספר והשם ריקים.

## 🚀 3 צעדים פשוטים להחלת העדכון בשרת (VPS):

### שלב 1: העלאת 4 הקבצים המעודכנים לשרת (scp)
בטרמינל מקומי (PowerShell) במחשב (ודא שאינך מחובר ב-SSH):
```powershell
scp -i "C:\Users\natan\Downloads\ssh-key-2026-10-18.key" index.js session-manager.js dashboard-api.js users-manager.js ubuntu@82.70.210.206:/home/ubuntu/wa-rides-bot/
```

### שלב 2: התחברות לשרת ואיפוס סשנים ישנים (מומלץ)
התחבר ב-SSH:
```powershell
ssh -i "C:\Users\natan\Downloads\ssh-key-2026-10-18.key" ubuntu@82.70.210.206
```
מחק סשנים ישנים של נהגים (משאיר את תיקיית bot שלמה!):
```bash
rm -rf ~/wa-rides-bot/auth/sessions/*
```

### שלב 3: הפעלת הבוט מחדש ובדיקת לוגים
```bash
cd ~/wa-rides-bot
pm2 restart wa-bot --update-env
pm2 logs wa-bot --lines 30
```

## 🌐 עדכון ממשק הניהול ב-Netlify
מכיוון שהוספנו את תצוגת קוד ה-QR החי, ה-Tabs החדשים וכפתורי האיפוס:
1. גרור ושחרר (Drag & Drop) את תיקיית `dist` המעודכנת ישירות ל-Netlify בלשונית **Deploys**.
2. או הרץ `npm run build` אם Netlify מחוברת ל-Git שלך.

*(הערה לגבי מאגר GitHub: המאגר `https://github.com/net-free-blumi/wa-rides-dashboard.git` מוגדר כפרטי. כדי למשוך ישירות ממנו נדרש Personal Access Token או מפתח SSH משויך).*
