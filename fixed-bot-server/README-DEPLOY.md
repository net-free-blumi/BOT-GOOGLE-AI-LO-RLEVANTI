# מדריך הפעלה, פתרון באגי סינון, מניעת ספאם והרחבת ערים ארצית (גרסה 2.9)

## 📋 פירוט התיקונים המהותיים שבוצעו (גרסה 2.9):

### 1. 📴 פתרון באג "נסיעות עוקבות מאותו סדרן נעלמות" (למשל סדרן 0552683249):
- **שורש הבעיה:** ב-`dedupe.js` היה מפתח סינון כפילויות לפי `phone:${phone}|${price}`. כאשר אותו סדרן פרסם נסיעה ראשונה (למשל "המכללה לשוטרים & ד ב-50 ש"ח) ודקה לאחר מכן נסיעה אחרת לחלוטין (למשל "ד & קריה ב-50 ש"ח) – המערכת חשבה בטעות שמדובר באותה נסיעה וזרקה אותה!
- **התיקון:** המפתח השגוי הוסר לחלוטין. כפילות נבדקת כעת אך ורק לפי קישור הזמנה ייחודי עם מספר טיקט (`wa.me/?text=ת+12345`), טקסט זהה, או שילוב מלא של רחוב ספציפי ומחיר.

### 2. 🏘️ זיהוי קיצורי שכונות ורחובות שהתווספו:
- **רמג / רמא / רמב / רמד / קרייה / הקרייה:** "רמג - קרייה" מזוהה ומאושר כנסיעה פנימית מלאה.
- **מעבר מאות בודדת לשכונה מלאה:** נוספה תמיכה מפורשת בפורמט `ג לרמה ד`, `ד להישנה`, `ד לקריה`.
- **רחובות חדשים בבית שמש:** `קדושת אהרן` (בתוך הרמה), `הרצוג` / `הרב הרצוג`, `נהרדע`, `יואל הנביא`, `סמטת הגפן`, `הגפן`, `המכללה לשוטרים`, `אלישע הנביא`.

### 3. 🛡️ מניעת סינון שגוי של הודעות שיחה ומשטרות (המילה "אלה"):
- **שורש הבעיה:** בהודעת המשטרות: *"אני מכיר בדרך כלל בשעות אלה חוזר מהאירועים לבית..."*, המילה התמימה "אלה" הכילה אותיות א' + ל' + ה', ותפסה את הביטוי הרגולרי של רמה א' לרמה ה'.
- **התיקון:** הביטוי חודד לדרוש מרווח או מקף ברור לפני האות ל' (`(?<![א-ת])[א-ה]\s+(?:ל|אל)\s*[א-ה](?![א-ת])`), ובכך המילה "אלה" נפסלת לחלוטין.

### 4. 🚫 שער בנימין ומושב רוגלית:
- **שער בנימין / אדם:** הוסרה המילה הבודדת "בנימין" מרחובות בית שמש (הייתה שייכת ל"בנימין מינץ"), והוגדרו היישובים "שער בנימין", "גבע בנימין" ו"אדם" כערים חיצוניות בבנימין.
- **מושב רוגלית:** מוגדר כמושב אזורי (מועצה אזורית מטה יהודה / עמק האלה). הוגדר שבמצב "בית שמש (פנימי)" נלקחים אך ורק רחובות ושכונות עירוניות, ומושבים מתקבלים רק במצב צמצום ("שמש צמצם").

### 5. 🏷️ ניקוי חתימות תחנה וקישורי דרייבוט:
- חתימות קבועות של סדרנים כגון `‎⛔אור החיים🏅⛔ללא פון🏅` וקישורי `t.me/prod_drivebot` מנוקים עוד לפני ניתוח המיקומים, כך ששם התחנה לעולם אינו משבש את ניתוח מסלול הנסיעה.

### 6. 📢 פיצ'ר חדש: שידור הודעות בוואטסאפ לכל הנהגים (Broadcast Modal):
- נוסף כפתור ירוק **"שידור לנהגים"** בסרגל הכלים העליון.
- מאפשר לבחור בין שליחה לכל הנהגים המאושרים לבין נהגים שמחוברים כעת בלבד.
- כולל תבניות מוכנות (עדכון גרסה, תזכורת לילית, הודעה דחופה, בוקר טוב), סרגל עיצוב וואטסאפ (מודגש, נטוי, קו חוצה, מונוספייס) ותצוגה מקדימה חיה של בועת וואטסאפ אמיתית.
- קצה שרת מאובטח: `POST /api/broadcast` השולח הודעות עם הגנת הצפה (מרווח 600ms בין הודעות).
