# מדריך הפעלה, פתרון באגי סינון, מניעת ספאם והרחבת ערים ארצית (גרסה 2.8)

## 📋 פירוט התיקונים המהותיים שבוצעו (גרסה 2.8):

### 1. 🎯 פתרון באג נסיעות שנפסלו (למשל: "פ שמש 50 ש / חבקוק הנביא להר מירון"):
- **שורש הבעיה:** בבית שמש ישנו רחוב בשם "הר מירון" ורחוב "חבקוק הנביא". מנוע הזיהוי ראה את המילה "מירון", זיהה אותה כעיר מירון בצפון (ליד צפת), ומכיוון שמדובר בעיר חיצונית – פסל את הנסיעה אוטומטית!
- **התיקון המשולש:**
  1. נוספו הרחובות `הר מירון`, `חבקוק הנביא`, `כינור דוד`, `ריבל`, `תלמוד בבלי`, `אור שמח`, `ישעיהו הנביא`, `מנחם פרוש` לרשימת מוקדי בית שמש ב-`cities.json` וב-`streets-full.json`.
  2. נוסף מנגנון הגנה: כאשר נסיעה מוגדרת מפורשות כפנימית (`פ שמש`, `פנימי שמש`, `שמש פ`) ומחירה מקומי (עד 110 ש"ח), היא לעולם לא תיפסל בגלל שם רחוב המתנגש עם שם עיר רחוקה (כגון רחוב מירון, רחוב ירושלים, רחוב חיפה).
  3. הנסיעה מאושרת ומגיעה לנהג באופן מיידי.

### 2. 🛡️ פתרון באג נסיעות לא רלוונטיות (למשל: "סבא שמש 100 היוצרים"):
- **שורש הבעיה:** בסלנג של סדרני מוניות, "סבא" הוא קיצור נפוץ ל**כפר סבא** (רחוב היוצרים הוא אזור תעשייה בכפר סבא). הכינוי "סבא" לא היה קיים במאגר, ולכן המנוע לא ידע שמדובר בעיר חיצונית.
- **התיקון הכפול:**
  1. נוסף הכינוי `סבא` לערך כפר סבא, וכן עשרות קיצורים של סדרנים בכל הארץ (`פתח`/`פת` לפתח תקווה, `ראשון` לראשון לציון, `גבעז` לגבעת זאב, `גת` לקריית גת, `טלז` לטלזסטון, `שדה`/`איירפורט סיטי` לנתב"ג, `תלהש` לתל השומר, `ספר` למודיעין עילית).
  2. **בדיקת מסלול בינעירוני (Distinct Cities Guard):** כאשר מזוהות שתי ערים שונות בהודעה (למשל `סבא שמש`, `שמש ים`, `ים שמש 50`, `ביתר שמש`, `בב שמש`) – הנסיעה נפסלת מיד ממצב פנימי, גם אם המחיר נמוך.
  3. **חידוד מוקד מקומי:** כדי שנסיעה תיחשב פנימית, לא מספיק שמופיעה המילה "שמש" לבדה, אלא חייבת להופיע שכונה/רחוב/מעבר, או הצהרת "פנימי" מפורשת.
